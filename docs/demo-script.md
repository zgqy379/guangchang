# 演示叙事脚本：三家虚构公司

> Demo 与 Demo 视频全部使用虚构公司。演示真实公司的负面参数（画饼/加班）
> 有法律与公关风险。三家公司的参数已按 project.md 9.7 锁定。

## 人设卡

### 1. 不眠星云科技（Sleepless Nebula）
- **一句话**：高薪卷王，钱给够，命也拿走
- 参数：年薪 60 万（base 48 + 绩效 12）/ 下班 23:00 / 大小周 / 竞业 2 年 / D 轮
- 空间特征：一人高的钞票山泛蓝光，天空永远挂在凌晨的月亮，出口有铁栅栏，
  日历墙红绿相间（大小周）
- 演示台词："山是真高——但你抬头看看几点了。"

### 2. 慢山文旅（Slow Hill）
- **一句话**：低薪清闲，小而快乐是合法选择
- 参数：年薪 15 万 / 下班 18:00 / 弹性 / 远程混合 / 已盈利
- 空间特征：膝盖高的钞票山，永远夕阳，主空间+卫星营地（混合办公），地面有可拖动时间环
- 演示台词："山只到小腿——但你每天看到的都是这个夕阳。"

### 3. 追光新创（Chasing Light）
- **一句话**：画饼大师，期权的艺术
- 参数：base 18 万 + "价值 200 万期权" / 下班 21:00 / 天使轮 / 无偿加班
- 空间特征：矮山上悬浮巨大的薛定谔钞票云——但被防博弈规则（5.4）压缩成
  一小片半透明，标签写"期权视觉体积按规则封顶"
- 演示台词："他说值两百万。你看，规则只让它显出这么大。"

## Demo 标准动线（3 分钟）

1. **开场（30s）**：慢山文旅的夕阳里站定——"别听他说，自己来看"（slogan）
2. **单公司参数（60s）**：拖动下班时间滑杆 18:00 → 23:00，夕阳滑成凌晨月亮；
   拖动年薪滑杆，山实时隆起/缩矮
3. **A/B 对比（60s，重头戏）**：左不眠星云、右慢山同屏；同步拖薪资滑杆，
   两座山一起长——"钱和命，都在这一屏里"
4. **反画饼（30s）**：切到追光新创，薛定谔钞票云被防博弈规则压缩的瞬间特写
5. **收尾（冲刺）**：Avatar 沿地砖路走向自己的作品森林，回头望山——
   "我的森林，换你的山"
