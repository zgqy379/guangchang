# 2026-10-25 钞票山根因修复 · 深度审查轮（egolite 实测验收）

## 根因级发现（egolite 线上实测 + 代码审查）

1. **钞票山永远单层平铺**（C1）：`pyramidLayout` 的 `side=ceil(sqrt(N))` 恒有 `ceil(sqrt(N))²≥N`，
   任何金额都只堆一层——15万不可见（1.25cm 薄片）、100万是一块铺满展台的"红地毯"。
   核心产品意象"山"在渲染中不存在。→ 重写为 `layerLayout`：每层固定 3×3=9 沓、
   逐层居中 + 锥度收缩，金额差直接变高度差；水平 2.5× + 高度感知增强 16×（场景角标声明）。
2. **"天空细线"之谜**：展台描边 `lineSegments` 忘加 `-π/2` 旋转，6×6 方框直立在场景中。
   排查过程：场景图 dump → 二分隐藏 → orbit 拖拽定位。
3. **办公室怼墙**：SPZ 内容尺度不可控，人工位姿盲调无效（位姿扫描全黑）。
   → 用 `SplatUtils.SplatOperator + computeDenseBox(0.9)` 算内容包围盒，数学推导 Dollhouse 角视角。
4. Avatar 深色衣服在暗地板上隐形 → 展台加暖色 pointLight；初始 T-pose → 挂载即播 IDLE。
