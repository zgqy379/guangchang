- **视觉锤币面：真钞 ✗ 内容审核 / 逛厂币（虚构币面）✓ → 主路径定为"逛厂币"**，Instanced Mesh 几何不变、只换贴图（7.6 架构提前兑现价值）
- **Avatar 管线（10.26 验证）**：文生 3D（cartoon/G1-Turbo）→ OUS 上传 → auto-rig 全链路通；带骨骼 GLB 43MB 已存档；自拍→图生 3D 待真实照片；retarget 动画待测
- 资产策略：**全部预生成**（单次 ~80–108s，滑杆不可等）
- 资产管线（W2）：**✅ 10.26 夜已打通**：`gltf-transform optimize --compress draco --texture-compress webp`——逛厂币 21.05MB→**2.23MB**（-89%）、金币 16.04MB→**1.45MB**、图生 Avatar 20.41MB→**2.09MB**，全部进入移动端预算；产物已放 `web/public/assets/`，**首个真实 Aholo 资产（逛厂币捆）已接入 Demo 场景**（本地 Draco 解码器 `public/draco/`，不依赖 CDN）

- 偶发性：provider status=4 会偶发出现（绑骨首试失败、真钞必现失败）——**生成脚本默认带一次重试**，批量任务做好失败重跑
