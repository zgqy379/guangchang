## 一、项目本质（一句话对齐）

Vite + React 18 + @react-three/fiber v8 + three.js 0.169 的**纯静态 3D 前端**，
无后端、无数据库、无服务端渲染。所有 Aholo 3D 资产在**开发期离线预生成**后以静态文件进
`web/public/assets/`，运行时只做加载。

- 47 个 TS/TSX 文件，8,427 行（`StreetScene.tsx` 单文件 1,704 行 = 全仓 20%，God File）
- 五种运行模式：`single`（逛一家）/ `compare`（A/B）/ `office`（3DGS 漫游）/ `street`（64 摊街区）/ `gallery`（作品廊）
- 单一 npm 包：`web/`；仓库根 `tools/` 放构建期守门脚本与生成/部署脚本

### 三条 warning 的真实归因（已核实，非缺陷）

1. `[AvatarActor] avatar-walk.glb 缺少动画剪辑 → WALK 不可用`
   **误报，时序问题**：文件实测含 1 个 clip（`animation_1`，53 channels，54 nodes，与 idle 同骨架）。
   `AvatarActor.tsx:100` 的检查条件是 `roam && !walkAnims[0]`，而 `walkAnims` 由
   `<WalkClipLoader>` **惰性回填**，首次 render 时必然为空 → 必然先报一次。
   *（若后续要做无障碍/干净控制台，可改为「加载完成后再校验」，但当前不影响走路功能）*
2. `[AvatarActor] ...` 第二次出现 = 第二次挂载（街区块重进）。
3. `Failed to send ktracker event! Ktracker maybe unavailable`
   来自 `@manycore/aholo-viewer` 自带的遥测上报，纯第三方，不影响渲染。
