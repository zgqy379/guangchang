# 签名概念 · 数据即景观（Data-as-Landscape）

> 本项目在奖项评审里的「记忆点」不是 3D 城市——3D 城市到处都是。是把抽象的求职数据
> 变成**可以走进去、可以对照、可以验证的地形**。所有视觉决策必须服务这个签名；
> 任何让它滑向「通用 3D 城市模板」的改动都是负资产。

## 一、概念陈述

**逛厂把「薪资 offer」从一张表格变成一片地形。**

- 总包数字看不见摸不着 → **钞票山**：一层层真实码放，山高对总包诚实（放大 2.5× 已披露）
- 五险一金基数 → **碑身灯条**：一格就是一档缴纳
- 下班时间 → **碑顶灯色**：18:00 暖光，23:00 冷光，加班被看见
- 行业 → **四区色带**：金/紫/橙/蓝，颜色即导航，不必读字
- 64 家公司的 offer 并排 → **一条街区**：远看是城市天际线，走近是逐家议价的谈判桌

一句话 slogan（对外口径）：**「把画的饼，砌成真的山。」**（header 已在用，保留）

## 二、为什么这个签名能得奖

1. **诚实是稀有性**：数据可视化界普遍美化数据；本项目反着走——山不许虚高、放大要披露、低薪就是小山。评审见惯了「炫技 + 假」，「炫技 + 诚实」是反向记忆点（这是本项目的道德护城河，也是 report.typ 的叙事骨架）
2. **编码有图例**：碑高=总包·灯条=五险·顶灯=下班——三联编码一行图例讲清，评委 5 秒读懂。多数 3D 作品败在「看不懂你在编码什么」
3. **抽象与具象互为因果**：拖动滑杆（抽象参数）→ 山实时长高（具象地形）。因果链一眼可读，这是「可玩性包装」的最高形态：**玩的就是数据本身**

## 四、数据→空间编码总表（本项目的「词典」，新增编码必须入表）

| 数据维度 | 空间载体 | 诚实约束 |
|---|---|---|
| 总包 | 钞票山高度/体积 | 严格线性映射；放大系数常驻披露 |
| 五险一金 | 碑身灯条格数 | 一格=一档，禁连续渐变伪装精度 |
| 下班时间 | 碑顶灯色温 | 18:00 暖 → 23:00 冷，连续可读 |
| 行业 | 四区色带 + 门楣 LED | 色相锚点间隔 ≥60° |
| 公司稀有度 | 宝石 + 光柱档位 | S/A/B 三档，不做假连续 |
| 投递状态 | 绿信标 + ✓ 浮标 | 全场景唯一绿色语义 |
| 距离 | 邻近米数 + 小地图 | 三源互证（门牌/罗盘/米数） |

### 编码兵法（源自 benchmarks.md 面D 六案例的横向结论）

- **实体感来自密度而非精度**（Refik Anadol）：粒子/道具按数据分布成团即可，不必逐值精确
- **双编码同一维度**（地图地形渲染）：等高线（几何）+色带（颜色）同时编码一个数据，远看色带近看等高线——单厂「测绘工作室」基调的技术骨架
- **数据贴面**（VarCity）：把不可视数据画在建筑面上（四区色带同构；立面可承载行业薪资热度）
- **时间即导航**（NASA Eyes）：时间轴拖动改变全场景——工时天空的「一天回放」候选签名时刻
- **以物喻数**（The Pudding）：抽象数字换算成可感知实物（钞票山本身；报告书可加幽默换算标注）
- **图层开关**（数字孪生产品）：数据编码可开关（碑高/灯条/顶灯图例可交互化，奖评审「信息设计」加分项）

## 五、反模板纪律（判定「改动是否稀释签名」的四问）

1. 这个改动**让数据更可读**还是只是让画面更满？（加一棵好看的树 ≠ 签名；加一排「同行平均线」人偶 = 签名）
2. 这个改动**经得起盲审追问「为什么在这里」**吗？（夜景加辉光可以，加霓虹字牌装饰不可以——后者是「夜市模板」）
3. 这个改动是否引入了**未在词典里登记的新编码**？（未登记 = 私货 = 删）
4. 如果把 3D 场景换成任意其他城市，这个改动还成立吗？（成立 = 通用模板件，降权）

## 六、氛围基调（给每个美术轮次的「花钱感」标尺）

- **昼**：粉彩玻璃孪生的「产业园区开放日」——明亮、克制、规划感；天空有层次、影子落地（当前最大缺口）
- **夜**：「霓虹夜市 + 测绘图纸」——暖光池、冷窗格、黑场有微反光；不做赛博朋克（蓝紫粉 overload = 模板化）
- **单厂**：「测绘工作室」——山是展品，地面是图纸（等高线/标尺/网格），面板是仪器
- 判据一句话：每帧截图自问「像不像有人花钱做的」；花钱感来自**克制 + 一致**，不来自堆料
