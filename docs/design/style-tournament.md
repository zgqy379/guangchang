# 风格探索锦标赛（2026-10-28 · 循环工程的艺术风格搜索模式）

> 回答的问题：「粉彩玻璃孪生」是能救还是该换。方法：同机位成对比较（绝对打分已被证明随评审池震荡 ±0.5-1.0，成对二选一稳得多）。
> 与人类走廊测试互补：LLM 成对赛选方向，人类走廊版验证胜者「像不像花钱做的」。

## 一、参赛风格（第 1 轮，全部可用现有管线廉价产出）

| 代号 | 方向 | 实现 | 基准参照（benchmarks.md） |
|---|---|---|---|
| BASE | 现状·粉彩玻璃孪生 | 无（对照组） | v4 twin-style-spec |
| TOON | 高饱和 toon | tokens：天空加深加饱和、四区色饱和+10%、地面/路压深 | F1 动森、A6 Resn |
| BLUE | 数字孪生蓝图 | tokens：青灰天空、网格透明度 0.46→0.85、玻璃退成线框感 | A4 Antinomy 过程可视化、C4 蓝图纪律 |
| DUSK | 黄昏电影感 | 零成本：?hour=17 拍摄（暖金长影全天候化） | A1 igloo 光叙事、D2 teamLab 色温轮转 |

每风格拍同一组 3 帧：昼 hero（?hour=10）/ 昼 walk / 夜 hero（?hour=21）。DUSK 的昼帧用 ?hour=17。

## 二、评审协议（成对淘汰，不打分）

1. 每轮 2 名拆分制评审（新池，禁接触实现/历史分数）
2. 评审看到的是**成对图**：同一机位、两种风格并排（甲/乙随机左右，评审不知道代号）
3. 每对回答：哪边「更像有人花钱做的」+ 一句指认位置的理由；平局允许
4. 附加一问（看完全部后）：「四选一，你出货用哪版？」

## 三、判定与停止规则

- 某风格连续 2 轮（不同评审池）在对决中 ≥3/4 机位胜出且总决选获胜 → **当选**，其 tokens 转正为新基线，解冻视觉循环（在新基线上重跑关键单项）
- 无风格稳定胜出 → 基线保留（合法结论：瓶颈不在风格），转收编路线
- 胜者若为 TOON/BLUE 且方向成立 → 第 2 轮在该方向上加码变体（描边/饱和度梯度）再赛

## 四、工程实现

- 风格 = tokens.json 值补丁：`tools/style-sweep.py` 驱动（备份→写变体→npm run tokens→build→拍→还原），全程 ~15 分钟
- 交付图组：`docs/figures/style-tournament/<style>/`
- 红线照旧：DC 不变（全 tokens 级改动）；拍前见新 ✓ built；还原后 git diff 校验 tokens.json 无残留
