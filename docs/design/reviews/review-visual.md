## ③ 三条最有证据的优点

1. **四区色彩编码全端一致**：`street-2026-10-27-polish9/hero.png` 的分区色块与 `walk.png` 右栏「雷达罗盘 + 四区进度 + 邻近摊位」色标一一对应，`night/walk.png` 夜景下仍保持可辨——颜色即导航，这套体系是全部截图中最强的资产。
2. **投递闭环反馈完整且诚实**：`focus.png → deliver.png` 五处状态同步联动：顶部「简历已投递 · 星链科技 +10 XP」toast、摊位上方绿色「✓ 已投递」标、求职者进度 5/50→15/50、投递 0→1、邻近摊位「星链科技」行出现绿勾；`night/deliver.png` 与 `mobile-collapsed.png`（星链科技 4m ✓）同样成立，跨主题跨端无漏。
3. **参数化隐喻直观且口径诚实**：`single-low-polish9.png`（总包 15 万，矮红砖堆）→ `single-high-polish9.png`（总包 58.3 万，高大钞票山 + 木顶）体量差一眼可读，并常驻角注「钞票山 水平夸比较大 2.5× · 高度做感知增强 · 换算见报告附录A」，主动交代失真口径。

## ④ 三条最影响得分的短板

1. **内景过曝，核心动线门面被雾化**：`street-2026-10-27-polish9/focus.png`、`night/focus.png`、`mobile/focus.png` —— 中后段白色半透明玻璃面连成一片，HR 人物与背景小字标签（如「融资 545万 · 3 件作品」）均被雾化；夜间版出现纯白/纯黑硬切、中间调缺失。「进店见 HR」是评委必经场景，此处最伤成品感。
2. **浅色主题标签低对比，最差背景对比度漏验**：`single-2026-10-27/single-low-polish9.png` 与 `single-high-polish9.png` 左栏「HR 参数面板」五行滑杆标签（基础月薪/薪资结构/五险一金缴纳/期权奖金/实际下班时间）近白灰字压白底，几乎不可读；同布局的 `single-high-night-polish9.png` 夜间版正常——说明浅色主题的标签色令牌单独漏改，而非设计意图。
3. **夜景英雄图失明 + 移动端细节毛糙**：`street-2026-10-27-polish9/night/hero.png` 中央信标夜间不发光、路网标线消失、近黑区域约占一半，四区只剩暗色块，首图冲击力弱；`mobile/hero.png` 顶部导航逐字换行（「求职者」「逛一家」「A/B 对比」均断成两行，「招聘街区」按钮文字也换行）；`mobile-collapsed.png`（`mobile-expanded.png` 同为半透明底）场景内青色标签穿透面板、正压在「邻近摊位·码上互联」行上并遮挡其距离值。

### 次要问题（不影响主线评分，建议顺手修）

- `hero.png` / `night/hero.png`：左上象限被大片无细节灰屋顶占据，旗舰首图信息密度不均。
- `walk.png` 昼间远景建筑与天空泛白，与深色 UI 卡形成「上白下黑」断层；地面「互联网区」地贴文字几乎不可见。
- `night/walk.png` 左缘成组半透明白色广告牌面呈「鬼影」叠层，观感疑似渲染瑕疵。
- `mobile/walk.png` 虚拟摇杆位置略偏中，与角色动线区域重叠；底部公司卡遮挡约 1/3 画面。
