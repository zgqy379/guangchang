## 一、逐张观察笔记

### street（白天）

- **hero.png**：高空斜俯瞰。十字路口 + 中央广场光柱构图成立，四区屋顶色块（金 / 粉紫 / 橙 / 蓝）划分清晰；右上 Lv.1 进度 HUD、底部「点击地面开始逛 · 四区街道任你走」CTA 明确。白色空天空无内容，建筑为素色体块，屋顶细节弱；「作品廊 · 求职者独立空间」青色浮字直接压在屋顶色块上。
- **walk.png**：街面视点。蓝色「互联网区」拱门 + 右侧 01–04 编号摊位（红箱 + 蓝雨棚）+ 两名玩家角色，街道纵深感成立。左下摊位卡（星链科技 / 总包 80 万 / 下班 22:30 / 五险基数 0.6 + 三个动作按钮）、右栏罗盘小地图 + 邻近摊位米数 + 四区进度，信息架构完整。扣分：路面过宽、左侧大面空白墙显空；地面「互联网区」贴花在当前镜头朝向下倒置。
- **focus.png**：摊位内部近景。HR 角色居中，但多层半透明玻璃叠加 + 近白天幕，画面发灰发噪，人物与柜台淹没在透明面里；顶部青色浮字与右上浮字被 HUD / 面板切割，主体失焦。
- **deliver.png**：同机位投递反馈：toast「简历已投递 · 星链科技 +10 XP」+ 绿色「✓已投递」徽章 + 按钮态变化 + XP 15/50 + 邻近摊位 ✓，五重确认，闭环完整且冗余合理。

### night（夜间）

- **hero.png**：氛围成立（灯串、金色光点、中央光环），但大面积近黑，摊位与街道细节几乎全部消失，只剩屋顶亮块，读感像悬浮碎片而非建筑。
- **walk.png**：拱门发光 + 暖黄灯串，夜间氛围是全套截图里最好的；但左侧白色阶梯状墙体刺目（高亮白几何在黑场里像贴图错误），玩家剪影近黑难辨；地面倒置贴花依旧。
- **focus.png**：室内近白、室外近黑，白底浮字与浅背景对比不足；玻璃叠层噪点与日间同源。
- **deliver.png**：同上 + 投递反馈；反馈元素在暗景中反而更醒目，是夜间观感最好的一张。

### mobile（390×844）

- **hero.png**：顶部导航逐项折行（「求职者」「逛一家」「A/B 对比」「办公室漫游」全部竖排两行），进度 HUD 压场景上沿，页脚三行小字；场景与 CTA 尚可用，观感碎。
- **walk.png**：底部摊位卡约占 1/3 高，按钮触达面积足；右侧圆形罗盘控件语义不明（罗盘还是虚拟摇杆需猜）；编号摊位可读。
- **focus.png**：HR 特写清晰；青色浮字被右缘裁切；罗盘控件压在人物一侧。
- **mobile-collapsed.png**：近全高半透明面板（罗盘 + 邻近摊位 + 四区进度），信息密度合格；但面板下 3D 场景的青色文字透过浮层与「码上互联」等列表行文字相撞。
- **mobile-expanded.png**：展开态只剩顶部罗盘 + 邻近摊位，下方约六成纯黑无内容，3D 世界完全消失，观感近似空态 / 破损。

### single（参数 → 钞票山）

- **single-low-polish9.png**：左栏参数画板（15 万 / 12 薪 / 18:00）→ 右侧钞票山近乎平地（红色薄台），「自定义」招牌；底部诚实标注「水平对比放大 2.5× · 高度感知增强 · 公司间比例真实」值得肯定。扣分：左栏滑杆标签为暗灰低对比；右侧场景约九成空黑地面 + 生硬地平线，起始状态观感像「没加载完」。
- **single-high-polish9.png**：50 万 / 23:00 → 红色阶梯钞票山 + 金条顶，因果对照强烈，是全组最「愿意多看一分钟」的画面；「不眠星云科技」招牌与左侧选中 chip 一致。细节：总包算式「base 50 万 × 14 薪」按字面乘不出 58.3 万，口径书写易让用户生疑。
- **single-high-night-polish9.png**：夜景版红山在暗背景上依然可读，参数表达跨主题成立；左栏暗灰标签对比问题在夜间更明显。

## 三、总分

- **空间/体验总分：7.0/10** —— 街区骨架与引导反馈闭环成立，但摊位同质化、夜间与移动端可读性掉档，距商用 8 分线的差距集中在「看不清、认不出」。
- **视觉总分：6.5/10** —— 白天素模 + 白天空寡淡、玻璃叠层噪点、夜间黑场与白墙 glare 三处拉低质感；夜景灯串氛围与钞票山符号化表达是亮点。

## 四、三条最有证据的优点

1. **投递反馈闭环五重确认**：toast「简历已投递 · 星链科技 +10 XP」+ 绿色「✓已投递」徽章 + 按钮态 + XP 15/50 + 邻近摊位 ✓（deliver.png、night/deliver.png）。
2. **参数 → 可视化因果一眼可读**：15 万 ≈ 平地 vs 50 万红色钞票山 + 金条顶，下班 18:00→23:00 联动，且带诚实缩放标注（single-low-polish9.png / single-high-polish9.png）。
3. **导览信息架构完整**：拱门区名 + 01–04 编号摊位 + 罗盘小地图 + 邻近摊位米数 + 四区进度点击直达（walk.png、night/walk.png）。

## 五、三条最影响得分的短板

1. **摊位内部「玻璃噪点」**：多层半透明面板叠加近白天幕，HR 与柜台被淹没、主体失焦（focus.png 中央偏右；night/focus.png、mobile/focus.png 同机位）。
2. **夜间可读性塌方**：俯瞰全场近黑只剩屋顶亮块（night/hero.png 全幅）；街面左侧白色阶梯墙刺目、玩家剪影近黑（night/walk.png 左侧中部与中下）。
3. **移动端浮层与空态**：顶部导航逐项折行成竖条（mobile/hero.png 顶部）；半透明面板透出场景文字与列表相撞（mobile-collapsed.png「码上互联」行）；展开态下方约六成纯黑、世界消失（mobile-expanded.png 下半幅）。

## 六、风险提示

评委若恰好从「夜间街景」或「移动端展开态」任一截图入场，会把作品判为半成品——夜景光比与浮层底色是冲 8 分线前必须先修的两处，其次是摊位内部玻璃分层与摊位外观差异化。

## 七、附注（不计分的小口径问题）

- 总包算式书写：58.3 万与「base 50 万 × 14 薪」字面乘法对不上（single-high-polish9.png 左栏底部），建议改为可自验的算式或注明口径。
- 右侧圆形罗盘控件语义不明（mobile/walk.png、mobile/focus.png）：罗盘 / 摇杆 / 返回按钮需猜。
- single 模式起始态（15 万）场景约九成空黑（single-low-polish9.png），建议给最小可读的「种子」形态。
- 「多待一分钟」维度 7 分的依据：钱山实验与进度收集留人，但街道本身可逛内容密度低。
