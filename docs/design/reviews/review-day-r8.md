# 逛厂 · 第八轮昼间单项盲审（review-day-r8）

- 评审对象：docs/figures/street-2026-10-27-polish9/ 下 hero.png、walk.png、focus.png、deliver.png（均为 1280×720 昼间截图）
- 评审方式：盲审，仅依据截图画面本身，未读任何代码/文档；四张全部逐张看完后再评分
- 维度：色彩体系与四区识别 / 光照与投影 / 构图与视轴 / 文字可读性 / 第一眼商业感

## ① 昼间视觉总分：6.5 / 10

理由：UI 层（顶栏、暗玻璃 HUD、公司卡、footer）已具备完整商业气质、交互反馈闭环真实，但 3D 场景光照发灰过曝、主视觉俯视图以空屋顶为主体，整体停在"完整原型"而非"商业产品"。

## ② 两条最有证据的优点

1. **deliver.png — 投递反馈闭环完整且三处一致**：顶部 toast「简历已投递 · 星链科技 +10 XP」、摊位上方绿色「✓已投递」标牌、右侧面板「投递 1 / 15-50 XP / 星链科技 4m ✓」、底部按钮同步变为绿色「已投递」态——一处操作四处联动，状态语义与颜色（绿=成功、黄=XP）统一，这是真产品才有的反馈设计。
2. **walk.png — 街区级四区识别与信息卡层级清晰**：蓝色拱门「互联网区」+ 地面涂装 + 蓝玻璃雨棚 + 01/02 门牌构成同一色的完整识别系统；右下四区罗盘（智造/金融/互联网/文创）与 0/16 进度条对应；左下公司卡「S 星链科技｜总包 80 万｜下班 22:30｜五险基数 0.6」主次分明，黄底 S 徽标点睛。

## ③ 三条最影响得分的短板（按影响降序）

1. **hero.png（整幅）— 俯视主图以空屋顶为主体**：左上米色大屋顶与左下橙红大屋顶两块近单色平板占画面近半，无细节无投影层次；且左下 salmon 橙红与右上粉色色相接近，四区在第一眼难以区分；中右大片空灰地面无内容锚点。作为落地页"第一眼"，信息量与吸引力最弱。
2. **walk.png 上半部 / focus.png 背景 — 光照过曝发灰、投影无力**：两图天空与远处建筑泛白成片（walk 左上、focus 中后段近乎全白），物体几乎无落地投影，场景扁平缺纵深；hero 整体同样灰蒙。
3. **focus.png 前景与中部 — 杂物无序 + 低对比浮字**：地面散落蓝/白箱体与立柱无组织感，左侧灰色巨柱遮挡近半视线，占上半幅的青色玻璃顶过重；「作品廊 · 求职者独立空间」青色文字压在浅亮背景上几乎不可读；背后门洞成大块死黑。

## ④ 距商用 8 分线还差什么

一句话：还差"场景可信度"——统一曝光并压住过曝、让阴影落地（hero/walk/focus），把 hero 换成能看见街道与摊位的中低机位（或给屋顶加细节并拉开四区色距），清理 focus 前景杂物并解决低对比浮字；UI 层已过线，拖分全在 3D 场景本体。
