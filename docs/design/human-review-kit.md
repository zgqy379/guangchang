# 人类评审校准套件（2026-10-28 · 打破 14 轮 LLM 评审的信息茧房）

> 背景：R1–R14 全部是 LLM 只看截图，分数带 6.0–7.7、中枢 ~7.1，同帧跨池分歧 ±0.5–1.0。
> 人类盲审从未做过（盲区清单 #8/#10）。本套件 = 15 分钟/人的结构化流程 + 判决树。
> **判决逻辑**：人类反馈直接决定走「收编路线」（叙事补分）还是「美术重置」（换风格）。

## 二、问什么（15 分钟脚本，按序问，录音或速记）

**第 1 分钟 · 盲答**（看完视频/站点后立即问，不给提示）：
- Q1 用三个词形容刚才的体验
- Q2 你记住了一个什么东西？（一句话）

**第 3 分钟 · 定位**：
- Q3 这是一个「有人花钱做的」产品，还是「学生/个人项目」？打分 1-10，理由必须指向画面具体位置
- Q4 和你看过的商业 3D 网站/游戏 UI 比，它站在什么位置？（前 10% / 中游 / 后 30%）

**第 7 分钟 · 逐帧巡诊**（10 张图快速过，每张只问一句）：
- Q5 这张图里最「贵」的元素是什么？最「廉价」的呢？（指认位置）

**第 12 分钟 · 判决性问题**：
- Q6 如果这个项目的美术方向（粉彩玻璃/霓虹夜市）保持不变，只把执行做到位，你愿意给它 8 分吗？（愿意/不愿意 + 缺的是什么）
- Q7 你会把这个链接发给朋友吗？为什么？

**第 15 分钟 · 开放**：
- Q8 如果你是主理人，接下来三周你只修一件事，修什么？

## 三、判决树（回收 2-3 份后我来分析）

| 信号组合 | 判决 | 行动 |
|---|---|---|
| Q3 均分 ≥7.5 且 Q6 多数「愿意」 | **7.0 平台主要是 LLM 评审噪声** | 走收编路线：冻结视觉，全力投导览模式/office 资产重生成/申报材料 |
| Q3 均分 <6.5 且 Q5 廉价感指向「白盒/粉彩风格本身」 | **风格中间态是真病灶** | 启动美术重置决策（高饱和 toon 方向预研 1 天后再定） |
| Q3 均分 <6.5 但 Q5 廉价感指向**具体清单**（如「街道太空」「立面太糊」） | **方向对、执行欠** | 按人类指认的清单打 2-3 轮定向循环（这次有真人锚点，不再震荡） |
| Q2 记不住任何东西 | **签名时刻失效**（比分数更严重） | 无论走哪条路，第一优先 = 评委导览模式 + 钞票山时刻强化 |

## 四、给评审人的补充说明（可选，回收后告知）

评审完成后可以告诉他们：这是群核 Aholo 全球 3D AI 黑客松的参赛作品，由多 agent 群体迭代了 14 轮盲审——他们的反馈将决定最后三周的方向。这句话能显著提高 Q8 的认真程度。

## 五、回收方式

- 每位评审一份 `docs/design/human-review-answers.md`（模板见同目录，复制后按人填充）
- 回收 2 份即可做初步判决，3 份更稳
- 拿到答案后整段发给我，我出判决 + 下一步执行计划
