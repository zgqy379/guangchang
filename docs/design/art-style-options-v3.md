# 逛厂 3D 街区 · 整体美术风格选型（10 选 1）

> 版本：v1.0（2026-10-26）
> 用途：为「逛厂 GuǎngChǎng」十字路口招聘街区选定整体美术风格方向。
> 前置文档：`docs/design/ui-system-v3.md`（UI 层已定为「厂玻璃」液态玻璃）、`docs/design/design-audit-2026-10-25.md`（盲审门禁 ≥7/10）。
> 检索来源：Awwwards 2026 Q1 趋势分析、Svilenković 3D 评析、Digital Strategy Force、ArtStyles、Pixel Studios、Out of Games、Tektite Studio、Digital Light Magic 三维美学体系、Concrete Brutalism 参考、虚拟展会/招聘会方案资料。

## 0. 先厘清一件事：UI 风格 ≠ 场景风格

液态玻璃解决的是 **UI 层**——浮在 3D 之上的信息载体（顶栏、HUD、名片卡、导航器）。
它对场景美术的影响只有两条，且已被 v3 方案锁死：

1. **亮玻璃需要深背景才成立** → 场景不能整体高明度，否则玻璃会"消失在墙里"
2. **玻璃是中性冷白** → 场景可以自由用暖冷对比，玻璃都压得住

所以下面的 10 个方向，**没有一个会被液态玻璃否决**。真正要选的是：3D 街区该长成什么样，才既过盲审 7 分线，又在 11.19 截止前做得完。

## 1. 三个硬约束（决定了方案的可行域）

### 约束 A · 资产现状：已有大量夜景资产，沉没成本在夜景

已建成并部署（不可轻易推倒）：
- 夜景窗格立面贴图 `facadeTexture()`（四面包 `MeshBasicMaterial toneMapped=false`）
- 64 盏路灯 + 地面暖光池（InstancedMesh）
- 四区牌坊 + 区色信标 + 中央图腾光柱
- 地面引导带（0.16m 细线）、车道虚线、道路路牌
- 雨棚 + 侧招立柱（摊位识别）
- 星空 `Stars` + 月亮本体（夜间专属）
- 钞票山 `MoneyMountain`（暗红发光材质）
- 4 套 Aholo 3DGS 办公室（室内，白天感）

**结论：偏离夜景（白天写实）需要重做大半场景资产 → 成本极高。**

### 约束 B · 已有系统被浪费：`sky.ts` 的工时天空

`sky.ts` 实现了完整的工时系统：17:00 午后 → 18:00 夕阳 → 19:30 暮色 → 20:00 起月亮渐高渐冷，附语义标签（"准点走的温度"/"深夜强度陈述"/"永远挂在凌晨的月亮"）。

但 `StreetScene` 默认 `offworkHour` 锁在**深夜**（互联网区 20–24 点区间），而各区真实区间本就有差异：

| 行业 | 下班时间区间 | 天然气质 |
|---|---|---|
| 智造区 | 17:30–20:00 | 傍晚收工，暖光 |
| 文创区 | 18:00–21:00 | 暮色，柔光 |
| 金融区 | 19:00–23:00 | 入夜，冷调 |
| 互联网区 | 20:00–24:00 | 深夜，霓虹 |

**结论：场景默认时段与四区差异化气质，是当前最大的未开采资源。**

### 约束 C · 距提交 24 天（11.19 19:00）

必须区分：**改参数（1–2 小时）** vs **改资产管线（3–5 天）** vs **重做场景（1–2 周）**。盲审提的"电影感灯光"属于前者；"摊位个体识别度"属于后者。

## 2. 全网检索的核心结论（5 条）

| # | 结论 | 来源 | 对本项目的含义 |
|---|---|---|---|
| 1 | **克制（Restraint）成为 2026 SOTD 第一特征**——赢在"只commit一个强视觉概念"，输在"效果堆砌" | Svilenković《Awwwards 2026 3D Sites》 | 四区四色 + 霓虹 + 辉光 + 体积光 = 典型堆砌。**必须选一个主概念，其余降级** |
| 2 | **真正打动人的是"具体的时空"而非"炫技"**。Jose and Goose 的街区模型用真实天文算法算太阳位置（经纬度 + 真实钟点），"这是某个具体时刻的某个具体地方" | Jose and Goose《A Live 3D Parking Model》 | 直接对应本项目**下班时间参数**——把参数做成真实时空，而不是抽象数值 |
| 3 | **暗色 + 金属金/铜点缀**是 2026 高端 3D 界面主流调性 | Svilenković SOTD 2026 | 与项目已有品牌红 `#FF5A3C` + 金 `#FFD24A` 天然契合 |
| 4 | **风格化优于超写实**，尤其在"信息密集、决策要快"的场景；且风格化更耐看、性能更好 | Pixel Studios / Out of Games | 64 摊位不可能靠贴图做出个体差异，**必须靠剪影/体块/色块区分** |
| 5 | **"Light as material"（光即材料）**是商业级 3D 的核心判据——方向性阴影塑造体积感 | Concrete Brutalism / 三维美学体系 | 现有半球光 0.95 + 双平行光是"打亮"不是"塑形"，缺方向性阴影 |

> 盲审三轮共性问题（电影感灯光 / 摊位识别 / 地图导航）**与第 5、4 条完全对应**——说明盲审要的就是这两件事，而非更花哨的效果。

## 3. 十个风格方向

> 评级说明：**改造量**指达到可交付水准的估计工时；**盲审预期**是基于检索到的 2026 评析标准与本项目现状推断的分数区间，非承诺值。
> **资产兼容**列标注是否需要重做现有资产。

---

### ① 暮色工业电影感 · Dusk Industrial Cinematic ★推荐

**一句话**：把街区定在黄昏 18:30，向阳面暖金、背光面冷蓝，湿地面有反射——"下班时分，正在收摊的招聘会"。

**视觉要素**
- 天空：三段渐变（顶部深靛 → 中段琥珀 → 地平线暖橙），地平线附近压出余晖带
- 主光：低角度暖金平行光（仰角 8–12°），**投射长阴影**——这是"电影感"的真正来源
- 补光：冷蓝半球光（天 `#3d5a8a` / 地 `#1a1410`），强度压到 0.35，制造冷暖对冲
- 材质：地面加 roughness 0.25–0.4 的湿反射带（不需要真反射，用 `envMap` + 低粗糙度近似）
- 氛围：暖色路灯尚未全亮（部分 30% 亮度），营造"正在切换"的中间态

**为什么推荐**
1. **复用已有资产**：窗格立面、路灯、牌坊、引导带全部保留，只改时段与灯光参数
2. **激活被浪费的系统**：`sky.ts` 的暮色逻辑（`dusk` 分支）已写好，只是没被当默认值用
3. **天然契合品牌**：暖金余晖 + 品牌红金 UI = 一整套"收工时刻"的调性
4. **直击盲审第 1 条**："电影感灯光"——长阴影 + 湿反射 + 冷暖对冲是标准解法
5. **液态玻璃完美成立**：深靛蓝天幕 + 暖金地平线，亮玻璃压在上面层次分明

**改造量**：1–2 小时（改 `sky.ts` 默认时段 + `StreetScene` 灯光参数 + 地面材质）
**资产兼容**：★★★★★ 零重做
**盲审预期**：视觉 7.0–7.8

**风险**：黄昏下部分深色材质可能欠曝 → 需提 `toneMappingExposure` 或补环境光

---

### ② 真实工时 · Authentic Work Hours ★推荐

**一句话**：不设定"某个时刻"，而是让四区**各自呈现各自的真实下班时刻**——智造区黄昏收工、互联网区深夜霓虹。街区是一条时间轴。

**视觉要素**
- 四区用**不同的时间状态**（互联网 22:00 / 金融 20:30 / 智造 18:00 / 文创 19:30）
- 每个区有自己的主光角度与色温，跨区转场有明确的"时空跳变"
- 中央十字路口是"时空漩涡"：四条街的光在天幕上交汇

**为什么值得考虑**
- 这是**只有本项目能做**的方案——把"下班时间"这个参数从数字升级成空间叙事
- 完全契合 project.md 的核心立意："参数空间化"
- 差异化极强，评审一眼看出"这不是通用模板"

**改造量**：3–5 天（需按区拆分灯光与天空，`WorkdaySky` 需支持分区）
**资产兼容**：★★★★☆ 需改渲染逻辑，不需重做资产
**盲审预期**：视觉 7.5–8.2（若实现干净）· 空间 7.5+

**风险**：分区光照与全局雾冲突；实现复杂度高于 ①

---

### ③ 深空赛博 · Deep Space Cyber

**一句话**：纯黑夜 + 高饱和霓虹 + 全反射路面，接近《赛博朋克》游戏内景。

**视觉要素**：大面积深蓝黑、霓虹招牌主导照明、体积光束、地面镜面反射、强对比

**优点**：视觉冲击最强，截图第一眼抓人；与已有霓虹资产（牌坊信标、LED）契合
**致命问题**
- **与品牌红金冲突**：项目核心色是红金（钞票山、逛厂币），赛博朋克是青蓝品红
- **四区四色在霓虹下彻底糊掉**——行业色是核心识别系统，不能牺牲
- **千篇一律**：2026 年赛博朋克街区已严重同质化，评审疲劳
- **违背约束 C**：材质重做量巨大

**改造量**：1–2 周 **盲审预期**：视觉 6.5–7.2（易因同质化失分）

---

### ④ 混凝土粗野 · Concrete Brutalism

**一句话**：清水混凝土 + 锈蚀钢筋 + 安全黄警示，把招聘街区做成"诚实、笨重、不可粉饰"的工业体块。

**视觉要素**：混凝土灰阶为主（#D5D0CA→#2A2725）、木模板横向纹路、锈红 #8B4513 强调、巨型几何体、无圆角、方向性强阴影

**优点**
- **概念与项目立意高度一致**："把画的饼砌成真的山"——不粉饰、露结构
- 材质色板天然对应"披露参数"的诚实感
- 粗野风提供**极强的剪影差异**，正面解决"64 摊位同构"问题

**致命问题**
- **与 Aholo 3DGS 办公室资产完全冲突**：那是写实扫描空间，插进混凝土街区是风格撕裂
- 与品牌红金（暖色、精致）气质相冲
- 灰混凝土会与暗色 UI 玻璃争夺注意力

**改造量**：1–1.5 周 **盲审预期**：视觉 6.8–7.5（概念好但执行风险高）

**适合场景**：若决定**放弃 3DGS 办公室**，走纯概念路线，则此方案值得重新评估

---

### ⑤ 风格化微缩 · Stylized Miniature Diorama

**一句话**：把街区做成桌面上的**沙盘模型 / 手办场景**——俯视微缩视角、饱和糖果色、清晰剪影、虚化的环境。

**视觉要素**：微缩模型质感、景深虚化边缘、玩具化比例、鲜亮底色、等距或高机位

**优点**
- **信息可读性最高**：造型辨识度好，摊位个体差异一眼可辨
- 性能好、风格统一、衰减慢
- 微观尺度本身就是隐喻："招聘市场被缩小成一个可把玩的模型"

**致命问题**
- **丧失沉浸感与临场感**——本项目卖点是"把参数砌成真的山"，微缩化削弱"真实"这一击
- 与 Aholo 3DGS 写实办公室风格撕裂
- 与"街区招聘会"的场景叙事不符

**改造量**：1–1.5 周 **盲审预期**：视觉 6.5–7.0

---

### ⑥ 侘寂留白 · Wabi-Sabi Minimal

**一句话**：低饱和大地色、原木与混凝土质感、大面积留白、柔和天光。安静、克制、禅意。

**视觉要素**：米白 #E8DFD0 / 灰褐 / 原木 #C19A6B、大柔光、弱阴影、极少霓虹

**优点**：气质高级、阅读性强（浅色 UI 可行）、与"呼吸感/松弛感"文案契合
**致命问题**
- **违背约束 A**：现有夜景资产全部作废，需重做全部立面与灯光
- **丢掉工时叙事的视觉力量**：侘寂是静态的，本项目核心是"时间"
- 品牌红金在低饱和大地色里会显得廉价

**改造量**：1.5–2 周 **盲审预期**：视觉 6.5–7.2

---

### ⑦ 东方写意 · Oriental Ink Wash

**一句话**：水墨留白 + 青黛配色 + 写意造型，把招聘街区做成东方长卷。

**视觉要素**：宣纸质感、青黛/赭石/米白、墨色浓淡、笔触边缘、散点透视

**优点**：概念独特、辨识度极高、契合"把画饼砌成山"的东方语汇
**致命问题**
- **与"参数精确披露"的产品本质冲突**——写意模糊化与数据精确性相悖
- 64 摊位在写意风格下会更难个体区分（盲审重灾区）
- 与 Aholo 3DGS 写实资产严重冲突

**改造量**：1.5–2 周 **盲审预期**：视觉 6.8–7.5（概念分高、可读性分低）

---

### ⑧ 工业朋克 · Industrial Punk

**一句话**：裸金属管道、外露电缆、警示条纹、机油污渍——工厂车间式招聘会。

**视觉要素**：锈蚀金属、裸露结构、警示黄黑条纹、工业灯罩、蒸汽粒子

**优点**：与"智造区"气质契合、与粗野风同源但更暖、剪影强
**致命问题**：只适合智造区，做整条街违和；且"脏乱"与求职场景的期望不符

**改造量**：1 周 **盲审预期**：视觉 6.0–6.8

---

### ⑨ 玻璃数字孪生 · Glass Digital Twin

**一句话**：把街区渲染成**半透明线框沙盘**——数据可视化优先，参数以发光体积块直接悬浮在空间里。

**视觉要素**：半透明玻璃材质、线框网格、数据流光带、参数以体积/光柱呈现、极少的实体材质

**优点**
- **与项目定位 100% 吻合**："参数空间化 3D 平台"——界面即数据
- 天然解决"64 摊位同构"：每摊的参数不同 → 光的形态不同
- 与液态玻璃 UI 形成**材质语言的呼应**（玻璃 UI + 玻璃场景）
- 视觉上极度现代、专业

**致命问题**
- **丧失人情味**：求职场景需要"人味"，全数据化会像 dashboard 而非招聘会
- 与 Aholo 3DGS 写实办公室彻底割裂
- 与"HR 形象"资产价值冲突（HR 形象是本项目的重要资产）

**改造量**：1–1.5 周 **盲审预期**：视觉 7.0–7.8（概念强、人情味弱）

---

### ⑩ 暮色市井 · Dusk Bazaar（混合方案）

**一句话**：以 ① 暮色工业为底，叠加市井生活气——摊位挂灯串、地面摊布、纸箱、推车、烟气，让它像**傍晚热闹的夜市招聘会**而非冷峻的科技园区。

**视觉要素**
- 底子同 ①（黄昏暖金 + 冷蓝补光）
- 每个摊位加**差异化生活道具**（按 lot 哈希确定性抖动，避免同构）
- 摊位灯串、地面反光布、蒸汽/烟气粒子（表现"人烟气"）
- NPC 增加密度与停留动作（不只是来回走）

**为什么值得考虑**
- ① 解决了光影，⑩ 额外解决**摊位个体识别度**（盲审三大问题之二）
- "市井"调性与"逛厂""把画饼砌成山"的生活化叙事更亲和
- 打工人在夜市找工作的画面感，直击目标用户

**改造量**：3–4 天（灯光同 ① + 道具程序化生成 + NPC 行为）
**资产兼容**：★★★★☆ 加法为主，不破坏现有
**盲审预期**：视觉 7.5–8.2 · 空间 7.2+

**风险**：道具生成需程序化以避免资产管线；粒子效果在低端机有帧率压力

| ⑩ | **暮色市井** | 3–4d | ★★★★☆ | **7.5–8.2 / 7.2+** | 高 | 道具程序化、粒子性能 |

---

## 5. 我的推荐

### 首选：⑩ 暮色市井（内含 ① 的光照基线）

**理由**：它是唯一同时解决盲审三大共性问题的方案——

| 盲审共性问题 | ⑩ 如何解决 |
|---|---|
| 电影感灯光 | 沿用 ① 的暖金主光 + 冷蓝补光 + 湿反射 + 长阴影 |
| 摊位个体识别度 | 按 lot 哈希程序化生成差异化道具（灯串/摊布/纸箱/推车），打破 64 摊同构 |
| 地图导航信息 | 市井元素天然形成视觉地标（每个区的招牌/摊位形态不同）→ 小地图与罗盘有了对应物 |

而且**改动是加法**：现有窗格立面、路灯、牌坊、引导带、雨棚全部保留，只加光照时段调整 + 道具生成 + NPC 密度。

### 次选：② 真实工时

如果你希望最大化差异化与"这只有本项目能做"的叙事感，② 是最强选项。它把参数变成了时空，是概念层面的降维打击。代价是要给 `WorkdaySky` 做分区支持，工期多 1–2 天。

> **① 与 ② 可叠加**：先把 ① 的光照基线做掉（1–2 小时），再决定是否升级为 ② 的分区时差。两者不冲突。

### 若要"稳"：直接做 ①

若时间极度紧张（11.19 前还要留出盲审与部署缓冲），① 的 1–2 小时改动是性价比最高的选择——**用最小代价摘掉盲审扣分最多的"电影感灯光"**。

## 6. 选择后要做的事（以 ⑩ 为例）

| 步骤 | 内容 | 工时 |
|---|---|---|
| S1 | `sky.ts` 默认时段 → 18:30；确认 `dusk` 分支的天幕渐变在夜间资产下可读 | 30min |
| S2 | `StreetScene` 灯光重配：暖金主光（低仰角 + 阴影）+ 冷蓝半球补光 + 曝光回调 | 1h |
| S3 | 地面材质加湿反射带（低 roughness + 环境反射近似） | 1h |
| S4 | 摊位差异化道具（程序化，按 lot 哈希抖动） | 1.5–2d |
| S5 | NPC 密度与停留动作 + 烟气/蒸汽粒子（低端机降级开关） | 0.5–1d |
| S6 | egolite/Chrome 实拍对比图 + **独立盲审**（≥7 放行） | 1d |
| S7 | 同步 `design/tokens.json` 的 `scene.*` 令牌（新增颜色先入令牌再 `npm run tokens`） | 30min |

> 全程遵守项目铁律：颜色唯一来源是令牌；新增颜色先加 `design/tokens.json` 再跑 `npm run tokens`；部署前 dist 无 `*.ply`；线上做完整启动验收。
