## 二、每档必过的三条通用验收（不占工时，含在各验收动作内）

| | 验收 | 判定 |
|---|---|---|
| **G1** | **诚实性审查** | 全站文案对照禁止清单 → **0 处虚假承诺**（假进度条 / "AI 已还原" / 隐瞒 652s） |
| **G2** | **反羞辱审查** | 关键帧逐张查 → **0 处**求职者并排对比 / 排行；任一帧可见求职者展位 ≤ 1 |
| **G3** | **无障碍审查** | 纯键盘 + 读屏可完成投递全流程；对比度 ≥4.5:1 |

## 四、关键提醒（给实现者的三条最容易踩的坑）

1. **C5**：滑杆**只驱动建厂预览与对比页**，街区的 64 个摊位是**已发布快照**、只在加载时算一次 —— 违反这一条会直接爆 draw call 红线（≤200）。
2. **诚实**：全站**禁止**任何形式的假进度条与"正在生成 3D…"文案；生成服务跑在服务器上，Demo 未部署 —— 这是产品主张，不是功能缺失，**要进报告书**。
3. **互斥**：参数碑与悬浮三件套在交叉淡化期，**任一帧同一参数只能有一种形态**；滑杆拖动时也不得让两者同帧并存。
