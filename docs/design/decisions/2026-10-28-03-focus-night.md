# 设计决策纸 ③ · focus 前景清理 + 夜景照明收尾

> 基准参照：benchmarks.md A3 Lusion（一屏一主角）、A5 Unseen（暗场细线发光）、D2 teamLab（光池连续）
> 差距对应：R10 两评审共同第 1 性价比（特写遮挡包，B 判「修好可到 7.5+」）+ 夜景黑区吞内容（两轮共同）+ 昼鸟瞰浮字穿透（两轮共同）

## 做什么

1. **特写机位重构框**（RoamCamera focus 分支）：后退 5.8→4.4m、侧移 4.2→3.6m、眼高 1.85→1.62m、视点 1.15→1.22m
   ——HR 画面占比升、立柱从「穿身」退为「框边」、白围板顶沿降到腰线以下、背景圆柱/拱门字移出或让位。一次改动救 R10 五点位中的四个。
2. **参数碑可读性**：碑体日间提亮 + 双主题微自发光——它是「碑高=总包」的数据要素，不应是未贴面的黑洞。
3. **夜景屋脊微光**（1 DC）：夜间屋脊线改发光（行业色 ×0.45，basic 材质 instanceColor）——城市夜光分布的「建筑描边」层，
   同时解决 B 的「四区色相夜间不可辨」与 A 的「暗部无内容」；屋顶面保持暗（物理正确），只有脊线发光。
4. **环岛黑洞**：转盘基石夜面加暖辉光贴图盘（1 DC）+ 图腾柱身夜面自发光提档——白天地标夜间不再熄火（R9 B）。
5. **浮字衬底**：作品廊 Html 标签加深色药丸衬底（青字压橙顶 = R8 事故，两轮复审再点名）。

## 验收判据

- focus 帧：HR 全身（或至少膝上）可读、无杆件穿身、背景无「抽象斑点群」；盲审特写分 ≥7.0（R10：6.0）
- 夜鸟瞰：四区色相可辨（脊线微光）、环岛不再读作黑洞；夜 walk 不回退（≥7.2 锚点水位）
- DC 增量 ≤2（夜脊线 1 + 辉光盘 1）；浮字衬底后文字对比达标
- 工具门全绿；夜景无新噪点
