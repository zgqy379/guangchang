# 设计决策纸 ④ · 摊位海报 + 街道行道树 + 夜区可辨 + 天空中段

> 基准参照：benchmarks.md F1 动森（街道密度节奏 8–12m 锚点）、A6 Resn（idle 生命感）、E1 全景故宫（章节即景点）
> 差距对应：R11 共识清单 #1（特写摊位内部空——双评审新第一性价比）、#4（walk 左半空旷/纵深）、#2（夜四区只可辨 2.5/4）、#3（昼鸟瞰上缘融天）

## 做什么

1. **摊位岗位海报**（1 DC，128 实例）：每摊玻璃幕墙两侧各 1 张（门旁 ±1.9m），
   共享「职位排版」贴图（灰阶线稿：标题条/职责行/薪资 chip）×instanceColor 行业色染色。
   basic 材质自发光——白天是海报、夜间是发光屏（特写帧「这家人做什么的」的视觉答案）。
2. **行道树**（2 DC：干 1 + 冠 1）：四街人行带（灯柱外侧 ≈±8.2m）每 7.2m 一株 ×32，
   低模（圆柱干 + 二十面体冠），冠色 instanceColor 双绿抖动——街道纵深与密度节奏（动森 8–12m 锚点律）。
3. **夜屋顶提亮**：夜间 cap 行业色保留度 0.34→0.26（暗区屋顶色相向行业色回靠，四区夜间可辨 2.5→4）。
4. **天空中段加深**：theme.light.skyMid / fog #e4eef6→#dce9f4（鸟瞰上缘楼体不再融天）。

## 验收判据

- 特写帧：玻璃两侧岗位海报可辨（「这家人做什么的」有视觉答案）；盲审特写 ≥7.5
- walk：左半幅出现绿色纵深锚点（树），空旷感下降；盲审 walk ≥7.5
- 夜鸟瞰：四区色相可辨 ≥3.5/4；昼鸟瞰上缘楼体与天空分离
- DC 增量 ≤3（海报 1 + 树 2）；工具门全绿；夜景不回退
