# 设计决策纸 ⑤ · 夜鸟瞰发光信息层（方案 B 第 1 靶）

> 基准参照：benchmarks.md A5 Unseen（细线发光勾结构）、D5 数字孪生（图层思维）、R12 空间评审处方「沿街发光边——右下蓝区已经证明这条有效」
> 差距对应：R9–R12 四轮共同失分位——夜鸟瞰「橙区/紫区成片纯黑、摊位与街道生活不可见、中心柱近黑」

## 做什么

1. **沿街商店发光边**（1 DC，夜only）：每栋建筑底脚一条 6.4×0.16 行业色发光带
   （basic ×instanceColor 压至 0.55 明度——「店招灯带」语汇），四臂连续 = 夜鸟瞰的
   「沿街自发光信息层」；与屋顶夜脊微光（②的 1 DC）上下呼应构成建筑描边双线。
2. **摊位夜光提档**：棚下光环 night opacity 0.1→0.2（配方内参数，R12「摊位与街道生活不可见」）。
3. **图腾光柱增强**：中央光柱 additive opacity 0.12→0.2（夜鸟瞰地标存在的最后一档）。

## 验收判据

- 夜鸟瞰：四条沿街发光边可辨（四区色相在地平层可读，非仅屋顶）；盲审夜鸟瞰 ≥7.0（R9–R12 全部 <7.0）
- 夜 walk 不回退（≥7.0）；昼间零变化（全部改动 night-only）
- DC 增量 ≤1（夜only）；工具门全绿
- 两轮内未达 7.5 → 按呈报约定冻结视觉（方案 B 上限）
