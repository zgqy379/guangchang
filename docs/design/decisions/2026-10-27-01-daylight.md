# 设计决策纸 ① · 昼间光照与投影（含截图时间确定性）

> 循环：设计决策 → 实现 → 截图（egolite）→ 拆分制盲审 → 归档 → 提交
> 基准参照：benchmarks.md A1 igloo inc（天空层次/暖焦点）、A3 Lusion（一屏一主角——本项不做机位，只做光）、C1 NASA Eyes（真实时刻陈述）、D2 teamLab（地平暖带连续性）
> 差距对应：gap-report #1（昼间天空白洞+无影）、#9 部分（hero 洗白）；R8 处方「统一曝光让阴影落地」

## 发现（本决策的根因，参数微调不收敛的原因之一）

**截图管线的时间伪影**：`shoot-ego-street.mjs` 只锁主题不锁时间，`envHour` 与太阳位置取真实系统时钟
（App.tsx:190 / WorkdaySky now=new Date()）。polish9 全部「昼间」截图摄于 23:00 真实时钟 + 亮色主题 =
`skyFromEnv` 走 `below=true` 分支 → **合成黄昏**：太阳高度角 0.09rad（≈5°）、强度 0.8、duskT=1 全暖调。
八轮评审看到的「昼间泛白/无投影」混合了管线伪影与真实产品状态——**昼间从未被在真实正午下评审过**。

## 做什么（三件事，一次循环）

1. **确定性时间缝（测试基建）**：`?hour=10` URL 参数冻结 envHour 与太阳/月亮位置。
   生产不带参数行为完全不变；实现于 `engine/time.ts`（sceneNow），App/WorkdaySky/TwinEnvironment 三处接线。
   ——诚实性：这是截图可复现性的测试缝，不是面向用户的功能，不进 UI。
2. **真实正午基线**：时间缝落地后先拍 `?hour=10` 基线（不改任何视觉参数），供光照改造前后对照与决策校准。
3. **光照改造**（视基线校准后实施）：
   - 天空层次：拓宽天顶-地平线明度差（ThemeLightSkyTop 深一档），加**慢漂云带**（2–4 片加性软贴图 sprite，随 envHour 色温）——sky 有内容可读，建筑与天空分离
   - 阴影落地：建筑脚下**接地暗影贴图**（radial 暗纹理 InstancedMesh，1 draw call）——贴地感不依赖 shadow map 分辨率；shadow extent 48→44 覆盖最远楼体（SLOT 最远 ≈39+3.2）
   - 曝光/雾：按基线判定（fog #e4eef6 在 60m+ 距离的洗白贡献待基线量化后调）

## 验收判据（charter §1 光影，可证伪）

- `?hour=10` 昼 hero/walk 截图：**至少一处可读定向投影**（建筑→地面、方向一致）；天空三段渐变天顶-地平明度差 ≥15%；建筑与天空剪影可辨
- 夜景（hour=21）不回退：R7 夜专项分不低于 7.0 水位（锚点图比对）
- 盲审提问「影子从哪来？」有共识答案
- 预算：draw call 增量 ≤2（云带 1 + 接地暗影 1）；首屏体积不增
- 工程红线全绿：typecheck / check-contrast / check-panel-ink

## 不做什么

- 不动 hero 机位（留给单项②与屋顶细节联合决策——每次循环一个变量，归因干净）
- 不引 postprocessing 包、不加真体积光（A1 的雾+辉光带替代路线）
- 不改夜间配方（R7 刚验收过的成果不回退）
