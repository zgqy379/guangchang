> **检索方法与诚实标注**：本清单在模型并发受限（WebSearch/子代理通道被限速）的条件下完成，
> 验证通道为 curl 直抓源站。三级标注：
> **✓页面验证** = 本轮 curl 抓到源页并核对标题/元数据；
> **documented** = 公开记载广泛、行业共识明确，但本轮未抓到源页（JS 渲染或超时）；
> **未验证** = 存疑，待补查。检索盲区如实列出（见文末），不编造奖项事实。

## 面A · Awwwards 3D 标杆（8 案例）

### A1. igloo inc（✓页面验证：awwwards.com/sites/igloo-inc 记 SOTD；「2024 年度站点」为广泛报道·未验证本轮）
- **它是什么**：Pudgy Penguins 母公司的冰川主题叙事站，全 WebGL 冰雪世界
- 八维：光影＝雾中光柱+冰面透光｜材质＝冰的折射/磨砂/洁净三态｜配色＝极冷底+单一暖点｜排版＝细大字、低密度｜动效＝滚动驱动长镜头｜交互＝滚动即叙事｜信息设计＝章节嵌入地形｜氛围＝纪录片级
- 可偷 3 手法：① 大尺度雾+地平辉光带就能造「体积感」，不必真体积光（成本差 10 倍）；② 冷色场景里**每帧保留一个暖焦点**作视觉锚（我们夜市路灯已是同语汇，可升级为构图纪律）；③ 相机由行进/滚动给进，杜绝自由漫游的迷失感
- 不适用原因：实拍扫描+定制 shader 团队预算与我们不匹配

### A2. Bruno Simon Portfolio（bruno-simon.com ✓ + awwwards SOTD ✓）
- **它是什么**：开着 3D 卡丁车逛的作品集，游戏化导航鼻祖
- 八维：光影＝柔定向影+贴地 AO｜材质＝低模纯色+要害物高细节｜配色＝低饱和底+高饱和交互点｜排版＝DOM 承担、3D 内浮字极少｜动效＝物理 everywhere｜交互＝开车一个隐喻贯穿｜信息设计＝路径即菜单｜氛围＝「作品集可以玩」
- 可偷 3 手法：① 「地面即菜单」：路面上画引导箭头序列替代部分 UI（我们动线已同构，可再强化）；② 低成本物理反馈：可撞的小道具（锥桶/硬币）用 InstancedMesh 一批；③ **加载期可玩**的诚实占位——与禁假进度条铁律同向
- 不适用原因：完整物理引擎的包体与移动端帧预算冲突

### A3. Lusion v3（lusion.co ✓ + awwwards SOTD ✓）
- **它是什么**：以软体/粒子物理著称的工作室自站
- 八维：光影＝studio HDRI+指针跟随光斑｜材质＝果冻感 SSS 假次表面｜配色＝近黑底+霓虹点缀｜排版＝一屏一句｜动效＝严格节拍编排｜交互＝指针即触发器｜信息设计＝作品即展品｜氛围＝实验室
- 可偷 3 手法：① **一屏一主角**纪律：每屏只有一个视觉主体（我们 hero 现在屋顶与图腾抢戏，直接适用）；② 一个跟随指针的 pointLight 假「材质响应」，便宜且高级；③ 进场动效按 0.1s 节拍表编排，不自由发挥
- 不适用原因：真软体物理的 GPU 预算不可得

### A4. Antinomy Studio（antinomy.studio ✓ + awwwards SOTD ✓）
- **它是什么**：WebGL 工艺流工作室，以引擎级管线与暗色空间著称
- 八维：光影＝人工光叙事、暗部有形｜材质＝自定义 shader 层级｜配色＝黑+单色相渐变｜排版＝极简导航｜动效＝转场即世界观切换｜交互＝探索式｜信息设计＝过程可视化｜氛围＝工程诗意
- 可偷 3 手法：① **窗格明暗即信息**：立面亮度分级承担构图（我们立面夜景化的直接范本）；② 全站光效用一个后期 bloom 收口（我们不引 postprocessing 包，则以加性贴图纪律替代）；③ 把**过程（线框/节点图）当内容展示**——本项目八轮盲审过程即作品，同构叙事
- 不适用原因：每项目定制引擎管线的成本不可复制

### A5. Unseen Studio（unseen.co ✓ + awwwards SOTD ✓）
- **它是什么**：暗色优雅的品牌数字工作室
- 八维：光影＝细线发光勾结构｜材质＝微反光暗面｜配色＝黑金/黑白｜排版＝大衬线字张力｜动效＝长 ease（>2s）缓动｜交互＝极简点击｜信息设计＝克制的层级｜氛围＝高定
- 可偷 3 手法：① **1px 级亮线勾勒结构**——夜间立面底缘反光条/碑体描边同款语言；② 长缓动造「贵」感（相机/浮层 ease ≥1.5s）；③ 暗场排版对比度靠「字重+字距」而非纯加亮
- 不适用原因：纯暗主题与本项目昼/夜双主题不同构

### A6. Resn（resn.co.nz ✓；awwwards 案例页 slug 未验证）
- **它是什么**：以俏皮生物与迷幻色彩著称的新西兰工作室
- 八维：光影＝舞台化聚光｜材质＝釉面卡通｜配色＝高饱和撞色+黑描边统一｜排版＝图形化文字｜动效＝夸张弹性｜交互＝逗弄生物｜信息设计＝弱、体验优先｜氛围＝游乐园
- 可偷 3 手法：① **idle「呼吸」微动**：静物加 0.5° 摇摆/呼吸就活了（雨棚/图腾顶珠适用）；② 撞色靠黑描边与投影统一，不靠降饱和；③ 一次性彩蛋（点第七下才出现的动作）——easter-egg 级细节的宪章要求来源
- 不适用原因：生物建模与骨骼资产成本

### A7. Active Theory — Paper Planes（documented；activetheory.net 抓取超时）
- **它是什么**：全球用户折纸飞机放飞互相捕获的现象级交互（2015-16，FWA/Webby/戛纳广泛记载·奖项细节未验证本轮）
- 八维：光影＝柔雾天光｜材质＝纸质感｜配色＝海天蓝白｜排版＝极简｜动效＝飞行物理｜交互＝折/放/追三动作｜信息设计＝**全球数据空间化**（每架飞机=一个人）｜氛围＝温柔的世界感
- 可偷 3 手法：① **高频轻反馈**：每次手势都有视听回应（走路的脚步声/地面涟漪级）；② 数据点变成可触碰物——「数据即景观」同源思想；③ 5 秒 onboarding：进场即懂，零说明书
- 不适用原因：全球实时采集后端不可复制

### A8. zengarden.ai（未验证：抓取超时，奖项存疑——按盲区处理，案例要点仅作参考）
- 可偷：留白即景深、单色相渐变天空的层次。不适用：AI 生成资产依赖与我们的诚实口径需甄别。
- **教训**：此条为检索通道受限下的诚实降级——宁可标注存疑不编造；后续通道恢复可补验证。

## 面B · FWA / Webby / 跨媒体叙事（4 案例）

### B1. Spotify Wrapped（documented；Webby 多年记载·细节未验证本轮）
- **它是什么**：年度个人听歌数据的故事化卡片流
- 八维：光影＝平面渐变舞台光｜材质＝扁平+噪点纹理｜配色＝年年度撞色主题｜排版＝超大数字+贴边排版｜动效＝卡片节拍切换｜交互＝单向滑动流｜信息设计＝个人数据戏剧化｜氛围＝身份认同
- 可偷 3 手法：① **把用户行为变成景观**：我们可把「求职足迹」（已投递/参观）画成街区里的可见痕迹；② 移动竖版构图纪律；③ 分享卡片即传播——A/B 对比页可出「对比卡」
- 不适用原因：需要真实用户数据规模化，演示数据下只可借构图

### B2. NYT «Snowfall: Avalanche at Tunnel Creek»（documented·2013 普利策）

- 可偷 3 手法：① 滚动锚定的全屏插页（报告书/导览模式适用）；② 文字段与全屏媒体交替的呼吸节奏；③ 图注排版规范（斜体+来源+透明度分级）
- 不适用原因：长文叙事与工具型产品形态不同

### B3. The Boat (SBS)（documented·获奖交互叙事）
- **它是什么**：越南难民题材水墨 HTML5 叙事
- 八维：光影＝水墨晕染｜材质＝手绘纸纹｜配色＝墨+朱｜排版＝竖排融入画面｜动效＝**环境随叙事强度变速**｜交互＝轻触发｜信息设计＝无、叙事优先｜氛围＝沉浸悲怆
- 可偷 3 手法：① 环境 BMI：背景动效（雨/浪/星空）随情节强度变速——我们工时天空可借「时段强度」律；② 声音作叙事主线（后续声音轮的范本）；③ 文字融入 3D 场景而非浮于其上
- 不适用原因：手绘扫描资产成本

### B4. Operation Night Watch（Rijksmuseum · documented）
- **它是什么**：伦勃朗《夜巡》亿级像素修复研究的公开站
- 八维：光影＝原作摄影布光｜材质＝油画肌理级呈现｜配色＝博物馆白+金｜排版＝学术注释规范｜动效＝渐进式放大｜交互＝图层开关（可见光/X光/UV）｜信息设计＝**研究过程即内容**｜氛围＝严谨的敬畏
- 可偷 3 手法：① 过程可视化=信任资产——本项目八轮盲审档案同构（report.typ 直接引此范式）；② 超大资产的**诚实渐进加载**（进度=真实字节）；③ 同一对象的「图层开关」信息设计——钞票山可加「薪资构成开关」（base/奖金/五险分层高亮）
- 不适用原因：博物馆级资产体量

## 面C · 机构级信息设计标杆（4 案例）
> 注：iF/RedDot/UX Design Awards 的获奖名单页为强 JS 渲染，本轮 curl 未获可验证具体案例——**如实记为检索盲区**，改以「机构级信息设计」标杆补位（这些机构作品与设计奖评审关注点同构：清晰、可访问、克制）。

### C1. NASA Eyes（documented，eyes.nasa.gov）
- **它是什么**：3D 太阳系/地球科学数据浏览器
- 八维：光影＝真太阳角照明｜材质＝贴图实测感｜配色＝深空黑+高亮标记｜排版＝任务徽章式标签｜动效＝时间轴驱动全场景｜交互＝click→fly-to 锁定｜信息设计＝**时间即导航**｜氛围＝任务控制中心
- 可偷 3 手法：① **时间轴即导航**：拖时间看全场景变化——工时天空可加「时间滑杆」直接展示 22:30 下班的街区（签名时刻候选）；② click→fly-to 相机锁定（我们 focus 相机的参照）；③ 真实数据驱动轨道=诚实可视化范本
- 不适用原因：科学精度与实时数据管线不同

### C2. Google Arts & Culture Experiments（documented）
- **它是什么**：艺术×数据的轻实验集（Art Palette、X Degrees 等）
- 八维：光影＝平面｜材质＝扁平｜配色＝藏品即色板｜排版＝细字说明｜动效＝轻转场｜交互＝即开即玩｜信息设计＝**一个实验一个洞察**｜氛围＝好奇心
- 可偷 3 手法：① 3 分钟讲完一个洞察的粒度——评委动线各屏的信息粒度标尺；② 颜色即数据（把对象按色彩空间组织——四区色带同构）；③ 截图即作品（分享动线）
- 不适用原因：依托博物馆馆藏数据集

### C3. Bloomberg COVID-19 Tracker（documented·多奖项记载）
- **它是什么**：疫情数据仪表盘的密度纪律范本
- 八维：光影＝无｜材质＝扁平｜配色＝少色+语义红｜排版＝大数字+趋势箭头标准化｜动效＝克制｜交互＝钻取｜信息设计＝**同一信息三级冗余**（数字/折线/地图）｜氛围＝可信
- 可偷 3 手法：① 关键信息三源冗余——我们寻路三源互证（门牌/罗盘/米数）已是同构，可将其升级为全站信息设计原则；② 数字「大字+变化箭头」标准化组件；③ 更新时间戳常驻=诚实
- 不适用原因：实时数据管线

### C4. Apple HIG Typography（✓页面验证：developer.apple.com/design/human-interface-guidelines/typography）
- **它是什么**：消费级排版系统的纪律参照
- 八维：光影＝-｜材质＝-｜配色＝语义色｜排版＝**语义字号阶梯+tabular-nums+Dynamic Type**｜动效＝-｜交互＝可访问性优先｜信息设计＝层级即语义｜氛围＝秩序
- 可偷 3 手法：① 字号阶梯**语义固定**（不自由起字号）：收口为 ≤5 级+语义名入 tokens；② 一切会变化的数字用 tabular-nums（HUD 计数/薪资/倒计时）——已写入宪章；③ 可访问性降级是排版的一部分（Dynamic Type≈我们 reduced-motion 的排版版）
- 不适用原因：native 与 web 度量体系差异

## 面D · 数据即景观（6 案例）——签名概念的核心弹药

### D1. Refik Anadol «Unsupervised»（MoMA 常设 · refikanadol.com ✓）
- **它是什么**：用 museum 藏品数据训练的「机器幻觉」数据雕塑，黑厅中一团发光数据云
- 八维：光影＝**自发光即唯一光源**｜材质＝粒子云雾｜配色＝黑场+高饱和流光｜排版＝无｜动效＝1/10 慢速流动｜交互＝凝视｜信息设计＝数据分布即形态｜氛围＝宗教感
- 可偷 3 手法：① **实体感来自密度而非精度**：粒子按数据分布成团即可（钞票山山顶「期权云」可借此做数据分布形态）；② 暗部微光不死黑的黑场范本；③ 慢速运动的高级感（0.1× 速度的环境动画）
- 不适用原因：真 ML 管线与实体展厅

### D2. teamLab Borderless（teamlab.art ✓）
- **它是什么**：无边界数字艺术博物馆，环境响应人的位置
- 八维：光影＝空间即画布｜材质＝光｜配色＝四季色系轮转｜排版＝极少｜动效＝**人走花开**｜交互＝身体即输入｜信息设计＝隐喻优先｜氛围＝忘我
- 可偷 3 手法：① **环境响应访客**：玩家走过的路面留 3s 光痕（一条 additive 贴图带，成本极低、生命感极强）；② 地面/墙/天幕同语言连续（我们天地分离感可由此收敛）；③ 昼夜/四季循环叙事——我们已有双主题，可加「黄昏过渡档」
- 不适用原因：实体空间与传感矩阵

### D3. The Pudding «Women's Pockets»（pudding.cool ✓·2018 广泛记载）
- **它是什么**：以「男女口袋装不下手机」的实物对比讲数据不平等
- 八维：光影＝-｜材质＝扁平插画｜配色＝编辑部级克制｜排版＝旁白式步进｜动效＝滚动步进｜交互＝阅读式｜信息设计＝**以物喻数**｜氛围＝幽默而锋利
- 可偷 3 手法：① **以物喻数**：抽象数字换算成实物尺寸对比——钞票山就是我们的「口袋」，可加换算标注（山高=多少台 iPhone 摞起来级别的幽默换算，仅报告书用）；② 滚动步进+一句旁白的信息密度纪律；③ 幽默感是传播力
- 不适用原因：编辑部人力模式

### D4. ETH VarCity（documented·苏黎世联邦理工）
- **它是什么**：城市级数字孪生研究，点云+语义分割承载城市数据
- 八维：光影＝实测光照模拟｜材质＝点云/网格混合｜配色＝语义色（建筑/植被/路面）｜排版＝学术标注｜动效=时间模拟（24h 日照）｜交互=图层钻取｜信息设计=**城市几何承载非可视数据**｜氛围=研究前沿
- 可偷 3 手法：① 把不可视数据**贴到建筑面上**（日照/噪声热力）——四区色带同构、立面可承载「薪资热度」；② 建筑 LOD 分级（远景剪影/近景细节）——draw call 预算的解法参照；③ 24h 时间模拟——WorkdaySky 已有雏形
- 不适用原因：研究级管线与点云资产

### D5. Cityzenith / 51World 城市数字孪生（documented）

## 横向综合：SOTY 级与「优秀」的分野（5 条）

1. **光影讲故事**：顶级案例的光永远有一个叙事焦点（每帧一个暖锚点/一个主角）；平庸案例的光是「均匀照亮」。我们的差距正是从「均匀」到「有焦点」
2. **一屏一主角**：Lusion/A1/A3 的注意力纪律——每屏一个视觉主体，其余全部退后。我们 hero 的屋顶抢戏是反例
3. **排版大而稀 vs 密而小**：西方标杆普遍「大字号+大留白+极少标签」；中文生态「密而精」。我们的解法=**世界内标签 diegetic 化**（画进路面/门牌），DOM 层只留主信息
4. **微动效生命感 > 大转场**：呼吸/浮动/响应指针的 idle 微动（Resn/teamLab）比炫技转场更能造「花钱感」；且成本低、不破帧预算
5. **诚实即高级**：Operation Night Watch 的过程公开、数字孪生的「真实即卖点」、Wrapped 的数据坦诚——与本项目「放大 2.5× 披露/无假进度条」同源，这是奖项叙事的护城河而非负担
