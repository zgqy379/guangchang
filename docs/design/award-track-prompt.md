## §提示词正文（整段复制）

你在接手「逛厂 GuǎngChǎng」（E:\guangchang）——群核 Aholo 全球 3D AI 黑客松参赛作品：参数空间化 3D 求职街区（React + three.js/R3F，web/ 单包）。你的使命不是修 bug，而是**把这个项目的视觉、交互、光影、材质、细节、配色、排版推到能角逐 Awwwards/FWA 级奖项的水平**，且不破坏任何已有工程纪律与诚实性底线。你可以自主检索、决策、实现、验证、迭代，只在做不可逆动作（部署/删数据/对外承诺）前停下问我。

### 第 0 步 · 深度检索（基准冲刺，先于一切实现）

1. **检索面**（每面至少 5 个案例，总计 ≥30 个）：
   - 奖项库：Awwwards（SOTD/SOTY/Developer Award）、FWA of the Day、Webby、SXSW Interactive、iF/Red Dot（数字类）、UX Design Awards；国内：站酷年度设计奖、金米奖、优设 UDC
   - 3D/空间标杆：Bruno Simon 作品集、Lusion、Active Theory、Monks、zengarden、igloo inc（Awwwards SOTY）、Antinomy Studio、Unseen Studio、Resn；中文语境：即刻/小红书被反复引用的 3D 品牌站
   - 相邻学科：任天堂/PlayStation 商店页的「可玩性包装」、动森/幻兽帕鲁的 UI 密度控制、Apple/猪八戒级别的排版系统
2. **检索产出物（必须落盘，不许口头总结）**：
   - `docs/design/benchmarks.md`：30 案例逐个拆解为 8 维度（光影/材质/配色/排版/动效/交互/信息设计/氛围），每案例给 3 个「可偷的具体手法」+ 1 个「为什么不适用本项目」
   - `docs/design/gap-report.md`：本项目当前截图（docs/figures/street-2026-10-27-polish9/ 14 张 + single-2026-10-27/ 3 张）逐维度对照基准打分（1-10），列出**最大差距前 10 名**及每项的基准参照案例
   - `docs/design/signature.md`：提炼**本项目独有的签名概念**（候选：钞票山/工时天空 = 「数据即景观」——把抽象薪资变成可走进去的地形；这是奖项叙事的核心，不许做成通用 3D 城市模板）
3. 检索阶段禁止写任何实现代码——先有审美判断，再有手。

### 第 1 步 · 设计宪章（不可妥协的质量线，写入 docs/design/charter.md）

逐维度写出**可验收的判据**（不是形容词），每条都要能被截图+盲审证伪。基线参考（八轮盲审已证明的短板）：

- **光影**：昼间必须有可读的定向投影与天空层次（禁止纯白天幕+无影平光）；夜间禁大面积死黑——最暗 15% 区域要有可读微反光；每盏灯在地面留光池；同一画面内光源数量≤3 种色温
- **材质**：任何表面禁止「无纹理纯色平涂」超过画面 20%；屋顶/大面积立面必须有细节（天窗/设备/分割线/橱窗）；3DGS/SPZ 资产必须过 Draco+纹理分级
- **配色**：四区色带即导航（金/紫/橙/蓝），全站色相≤主色+辅助+状态；禁止高饱和平涂色块无光照变化；文字对比度全场景 ≥4.5:1（WCAG AA，按最坏背景验算）
- **排版**：字号阶梯≤5 级；数字用 tabular-nums；标签近不可读=事故；中英混排基线对齐
- **动效**：入场/状态切换有 easter egg 级细节（粒子/光效/视差），但 prefers-reduced-motion 全量降级；禁假进度条
- **交互**：每个可点对象 hover/active/focus 三态齐备；触控目标 ≥44px；核心闭环（逛→看牌→投递）每步有独立视觉反馈
- **信息设计**：3D 编码必须配图例（碑高=总包·灯条=五险·顶灯=下班 已是标杆，保持）；任何浮字禁止穿透 UI 面板、禁止视口裁切
- **氛围**：每一帧截图必须能回答「第一眼像不像有人花钱做的」；交付物 = 每维度 1 张对标截图

### 第 2 步 · 循环工程（每个单项的完整轮次）

**单项循环** = 设计决策（1 页纸：做什么/为什么/基准参照/验收判据）→ 实现 → 截图（`tools/shoot-ego-street.mjs`，egolite 管线；长跑挂起换 `tools/shoot-street.cjs`）→ 盲审（2 名拆分制临时评审，只看截图 ≤8 图/人，禁止接触实现）→ 归档 design-audit → 提交。

**停止与换道规则**（八轮实证）：同一单项连续 2 轮盲审分不涨 → 换方案而非继续调参；三轮不涨 → 停下向主理人呈报，附截图对比与两个备选方案。**禁止刷分**：评审分数只用于验收，不用于向用户汇报「接近了」。

**预算红线**（违反=事故）：街区 draw calls ≤200（现 672，优化须 InstancedMesh 化）；首屏 ≤5MB；WCAG AA 全场景；Canvas 内禁裸 div/data-*；instanceColor 不开 vertexColors；阴影面必须挂贴图；tsc 失败 dist 不更新（截图前必须见新 `✓ built`）；凡碰街区渲染的提交当轮重拍四图。

### 第 3 步 · 本项目已知地形（读这些再动手，省你五轮弯路）

- 八轮盲审：视觉稳定 7.0 平台，八轮 agent 微调未收敛——你的价值在**设计决策**，不在参数微调
- 已根治勿回退：T13（Canvas 内裸 div/data-* = 白屏）、黑棚顶（vertexColors 无 color 属性=黑）、focus 白幕（无贴图白方块阴影面 ×64）、GcSelect 传 label 不传值、表单墨色 --ui-ink-* 误用
- 工具链：截图管线已迁 egolite（窗口最小化自愈已内建）；盲审用拆分制临时评审（≤8 图/人，16 图必挂）
- R7/R8 处方式清单（最高性价比顺序）：立面窗色分级+屋顶降温去饱和 → 特写补环境反光抬黑场 → 每盏灯光池+辉光 → 统一曝光让阴影落地 → hero 改中低机位或屋顶加细节 → focus 前景清理

### 第 4 步 · 止盈与交付

全部单项盲审视觉 ≥8 且无未处理事故后：按「功能/视觉修复版」口径部署（gh-pages + 魔搭配方见 docs/lessons.md §7.4 与 tools/ms-*.py/.mjs），线上验收（`tools/accept-live.mjs`），最后向主理人交付：8 维度前后对照图 + 奖项申报建议（投哪个奖、报什么类别、用什么截图组合）。

## 使用建议

1. **整段投喂**：把 §提示词正文作为新会话的第一条消息（或写入 AGENTS.md 临时附加段），配 `docs/handoff-2026-10-27-polish9.md` 作为状态输入
2. **分期启用**：若预算紧张，先只跑第 0 步检索 + gap-report（约半天），用报告决定动哪几个单项——检索产出物本身就是设计决策的弹药
3. **不要混合**：检索期与实现期分开会话跑，避免上下文互相污染
