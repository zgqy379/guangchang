## 一、逐维度打分（当前 = polish9 终版）

| 维度 | 分 | 一句话判断 |
|---|---|---|
| 光影 | **5.0** | 昼无投影+天空白洞；夜黑场失控与局部优秀并存——八轮最痛处 |
| 材质 | **5.0** | 大面积平涂：空屋顶/空立面/塑料感钞票山；玻璃孪生是唯一亮点 |
| 配色 | **6.0** | 四区色带导航成立；昼间粉彩洗白与高饱和屋顶互相打架 |
| 排版 | **7.0** | UI 层字号阶梯/信息层级合格；3D 浮字（青字压浅底）拖后腿 |
| 动效 | **6.0\*** | 截图介质无法评审；生长动画/投递光效存在但从未被盲审（\*低置信） |
| 交互 | **7.5** | 投递五重同帧反馈是全项目最强资产；三态/44px 未系统验证 |
| 信息设计 | **7.5** | 「碑高=总包·灯条=五险·顶灯=下班」图例是奖项级资产，保持勿动 |
| 氛围 | **5.0** | 昼间「像渲染测试」；仅 night/walk 一帧「像有人花钱做的」 |

加权综合 ≈ **6.1**（按视觉权重）；与八轮盲审中枢 7.0 的差值来自：本表按「对标基准案例」的绝对尺度打分，盲审评审在没有对照物时更宽容。两套尺度共同指向同一结论：**光影与材质是断崖，信息设计与交互是长板**。

## 二、最大差距 Top10（附证据帧与基准参照）

### 1. 昼间天空系统缺失：白洞 + 无影平光
- **证据**：`walk.png`（天空纯白，建筑剪影几乎融进背景）、`hero.png`（左上角洗白）
- **基准**：Bruno Simon 作品集（天空渐变穹 + 柔和定向影）、igloo inc（天空有深度层次，天光参与照明）
- **差距机制**：当前昼间 = 高亮度 HemisphereLight + 几乎无效的平行光阴影；「白天空 + 白建筑 + 灰地面」三者明度接近，画面没有明度骨架
- **成本**：中。天空穹三段渐变 + DirectionalLight 阴影参数整定（shadow camera 范围/bias/分辨率）+ 地面接触阴影加深

### 2. 屋顶 = 画面近半的无细节色块
- **证据**：`hero.png`（左上米色 + 左下橙红两块空屋顶占近半）、`mobile/hero.png` 同病
- **基准**：动森（屋顶脊线/瓦纹/烟囱等母题）、igloo inc（任何大面都有微表面）
- **差距机制**：屋顶是鸟瞰机位的第一大画面占比面，当前是高饱和平涂 + 零细节；且橙红与粉区色相相近，四区导航失效
- **成本**：中低。降温去饱和（屋顶色退出主色竞争）+ 天窗/设备箱/边缘压线条纹 + 四区锚点色相重选（金/紫/橙/蓝拉开 60°+）

### 3. 夜间鸟瞰黑场失控
- **证据**：`night/hero.png`（街面与侧街 40%+ 纯黑，灯池只沿主街）
- **基准**：igloo inc（最暗 15% 仍有微反光）、Refik Anadol 式「黑场也有内容」的光分布
- **差距机制**：R7 夜景 v2 只治了天际线与窗色；地面光池未连成网，黑场里没有「城市的呼吸」
- **成本**：中。灯池沿全路网（InstancedMesh 光池贴图）+ 路面夜反射带延伸 + 摊位棚下光外溢半径

### 4. 立面高饱和平涂（夜景化未完成）
- **证据**：`night/focus.png`（背景立面大色块）、R8 判语「高饱和平涂色块、屋顶亮平如白天」
- **基准**：Unseen Studio（立面亮度分级节奏）、Antinomy（窗格明暗即信息）
- **差距机制**：窗色两档已做，但立面**底色**仍然白天饱和度；夜景立面应整体退成剪影+窗点
- **成本**：低。夜间立面底色 ×0.4 去饱和 + 底缘环境反光条 + 窗点亮率按区差异化

### 5. 单厂低值端空间叙事崩塌（产品级尴尬帧）
- **证据**：`single-low-polish9.png`（60% 黑地板 + 天际线一条棕雾 + 小红堆）、`single-high-polish9.png`（70% 空）
- **基准**：The Pudding（数据页每寸都有信息）、teamLab（空场即留白设计而非渲染残留）
- **差距机制**：低总包 = 山小 = 场景空；这是「数据即景观」签名概念的**诚实**面（山不能虚高），但空场不是留白是荒地
- **成本**：中。参数化道具群（刻度人偶阵列=同行对比、五险柱廊、期权云、下班月亮随时间升落）+ 地面等高线/坐标网格纹理（测绘感）

### 6. 街道纵深与沿街立面内容为零
- **证据**：`walk.png`（左半幅空沥青）、`hero.png`（中右空灰地面）
- **基准**：动森（街道密度节奏：树/椅/店招每 8–12m 一个锚点）、Bruno Simon（场景道具的视觉节拍）
- **差距机制**：街宽 6–8m + 无次级地标 → 行走 30 秒后画面停止给新信息
- **成本**：中高（注意 draw call 预算）。InstancedMesh：行道树/长椅/路障/橱窗内容/停靠车辆

### 7. 钞票山塑料感（签名时刻的材质拖累）
- **证据**：`single-high-polish9.png`、`19-compare.png`（红色分层面团，无纸感）
- **基准**：任天堂商店页（主角物体的材质特写级打磨）、真实纸币堆的层缘参差
- **差距机制**：纯色 + 微弱砖线纹理；层缘无 AO、无纸页错位、无面额印刷
- **成本**：中低。canvas 生成纸币纹样贴图（面额+层线+±1.5° 抖动，规格已在 design-audit 二期待办 #1）+ 层缘 AO

### 8. A/B 对比页与单人页的「黑洞构图」
- **证据**：`19-compare.png`（70% 纯黑，B 标签右缘裁字）、single 系列（同第 5 条）
- **基准**：Apple 对比页（双栏对齐纪律、留白即设计）、Pudding（图表配轴/标注）
- **差距机制**：3D 区被当成「渲染视口」而不是「被设计的信息图」；黑背景上没有网格、轴、比例尺等测绘语言
- **成本**：低。地面淡网格 + 高度标尺 + 山顶数据浮标引线（诚实放大 2.5× 的标注已存在，缺的是测绘美学）

### 9. hero 第一眼机位 composition
- **证据**：`hero.png`（空屋顶占半、中右无锚点）
- **基准**：Bruno Simon（进站即见角色与世界的互动）、Monument Valley（封面级构图：主体/引导线/留白三段式）
- **差距机制**：机位与场景内容不匹配——鸟瞰是把「屋顶」当主角，而主角应是「街道与摊位」
- **成本**：低（机位）～中（若加屋顶细节）。二选一：hero 改中低机位看见街道纵深；或屋顶细节化后保留鸟瞰
- **注**：此项与 #2 联动，做一个决策纸

### 10. 性能预算爆线（奖项体验的地基）
- **证据**：`metrics-polish9.json`——hero 678 draw calls（预算 ≤200）；walk/focus/deliver **13.5–14.5 FPS**（目标 60）
- **基准**：所有 SOTD 案例共有的隐含门槛：流畅不是加分项，是入场券
- **差距机制**：64 摊 × 多部件独立 mesh；材质 programs 147 个
- **成本**：高（工程轮次，非美术轮次）。InstancedMesh 合批 + 材质图集 + LOD 分层；与 #6 街道纵深道具合并成一个工程决策纸，防止「加道具」与「降 DC」互相拆台

## 三、评委动线层的额外差距（不在 8 维内但影响奖项结果）

1. **办公室漫游（3DGS）**：`office.png`（10-26）取景入体 = 80% 画面是粒子糊墙，评语 3/10。polish9 未重拍此页——**必须重验**，若仍如此，评委走到第四屏会怀疑整个项目的完成度
2. **角色门（第一屏）**：从未被盲审；当前夜景鸟瞰背板尚可，但 CTA 文字被光晕吃掉一半
3. **A/B 对比页 B 标签裁字**：10-25 证据至今未重拍确认
4. **i18n**：全球黑客松，全中文 UI——国际评委的 30 秒弃用风险（需查提交通则再决策，不擅自加英文）
5. **demo-video.mp4 为旧构建**：评委第一眼是视频（见 design-audit 盲区清单 #1）

## 四、已经过线、列为「不要动」的资产

- 四区色带即导航（跨端一致的色彩编码）
- 参数碑三联编码 + HUD 图例（碑高=总包·灯条=五险·顶灯=下班）
- 投递五重同帧反馈（toast/绿标/进度/按钮态/3D 信标）——R1–R8 全部评审认可，动效强化可以，结构勿动
- 诚实性三件套：数据为示例样例标注、山体放大 2.5× 附录披露、无假进度条
- HUD/面板令牌体系与对比度管线（check-contrast/check-panel-ink 全绿）
