# 设计宪章 · 可验收判据（2026-10-27）

> 性质：所有视觉轮次的**质量底线与验收判据**。每条判据必须可被「截图 + 盲审提问 + 工具测量」证伪。
> 依据：主理人目标书 + R1–R8 八轮盲审实证短板（见 `design-audit-2026-10-25.md`）+ `gap-report.md` 差距报告。
> 冲突时：工程铁律（AGENTS.md）> 本宪章 > 单项设计决策纸。
> 流程铁律：检索期（benchmarks/gap-report/signature）禁止写实现代码；每单项走完整循环
> （设计决策纸 → 实现 → 截图 → 拆分制盲审 ≤8 图/人 → 归档 → 提交）后才算完成。

## 0. 通用验收协议（每个单项共用）

- **截图**：`tools/shoot-ego-street.mjs`（先跑 `tools/restore-ego2.ps1`；长跑挂起换 `tools/shoot-street.cjs`）；碰街区渲染的提交当轮重拍四图（hero/walk/focus/deliver，昼+夜）
- **构建门**：截图前必须看到新的 `✓ built`（tsc 失败 = dist 旧版 = 拍的是旧画面，八轮实证事故）
- **盲审**：2 名拆分制临时评审，只看截图 ≤8 图/人，禁接触实现；每轮固定送 2 张锚点图校准尺度（R1–R8 无锚点导致分数震荡的教训）
- **停止规则**：同单项连续 2 轮分不涨 → 换方案；3 轮不涨 → 停下呈报（附截图对比 + 两个备选方案）。禁止刷分
- **工具门**：`npm run typecheck` ✓、`node tools/check-contrast.mjs` ✓、`node tools/check-panel-ink.mjs` ✓（含 forms/）

## 1. 光影（当前 5.0 → 目标 ≥7.5）

- 昼间：画面中**至少一个可读的定向投影**（建筑→地面，长度/方向一致，同光源）；天空**禁止纯白/纯色平涂**（三段渐变或以上，天顶-天际-地平明度差 ≥15%）；建筑与天空的明度差 ≥10% 剪影可辨
- 夜间：**最暗 15% 区域**（截图直方图暗端）不得为纯黑 R=0——须有可读微反光；每盏路灯与摊位棚光在地面留下**椭圆光池**，光池沿街连续（断档 ≥3 处 = 不合格）；同一画面光源色温 ≤3 种
- 特写（focus）：HR 面部与下半身均可见（下半身没入黑场 = 不合格）；画面中同时存在主光/补光/轮廓光的层次
- 测量：截图直方图 + 盲审提问「影子从哪来？最暗处你能看见什么？」

## 2. 材质（当前 5.0 → 目标 ≥7.5）

- 任何「无纹理纯色平涂」表面**占画面 <20%**（屋顶、大立面是重点）；屋顶必须含 ≥2 类细节母题（天窗/设备箱/边缘压线/脊线，四区可复用同图集不同色）
- 钞票山（签名时刻）：近景可见纸币层线、面额印刷、层缘明暗差；禁止「塑料面团」观感
- 玻璃类：反射/透射/边缘三属性至少可见其二；禁止「无根漂浮的半透明面」
- 测量：hero+focus 截图 + 盲审提问「哪个面你认为是廉价的？」

## 3. 配色（当前 6.0 → 目标 ≥7.5）

- 四区色相锚点**间隔 ≥60°**（现行金/粉/橙红中粉-橙相近 = 改锚点），远距离鸟瞰下四区可辨识
- 全站色相 ≤ 主色 + 辅助色 + 状态色；高饱和大面积色块禁止（饱和度须随光照变化衰减——屋顶降温去饱和）
- 文字对比度全场景 ≥4.5:1，**按最坏背景验算**（半透明浮层背景是变量）；3D 浮字按其落点背景验算（青字压橙屋顶 = 已知事故，禁复发）
- 颜色唯一来源 = 设计令牌（CSS `var(--color-*)` / 3D `generated/design-tokens.output.mjs`）；改令牌必跑 `npm run tokens`
- 测量：check-contrast 全绿 + 盲审「四区分别是什么颜色？」

## 4. 排版（当前 7.0 → 目标 ≥8）

- 字号阶梯 ≤5 级；数字一律 `tabular-nums`（薪资/米数/进度对齐）；中英混排基线对齐
- 标签在最终截图 1:1 尺度下**必须可读**——「近不可读」直接计事故（青字压浅底教训）；3D 浮字距 UI 面板 ≥8px 且禁穿透（zIndexRange 已压 [10,1]，勿回改）
- 移动端 390px：顶栏不折行、CTA 不裁切、图例不溢出
- 测量：截图 1:1 检视 + 元素 metrics（layout.boxes 无 clipped/overlap）

## 5. 动效（当前 6.0* → 目标 ≥7.5，需录屏轮补证）

- 入场/状态切换有 ≥1 处「easter egg 级」细节（粒子/光效/视差）；生长动画 = 签名时刻，须在 5 秒内讲完「参数→山体量」因果
- `prefers-reduced-motion` 全量降级（悬浮/粒子/镜头运动三处必查）；**禁假进度条**（诚实是硬门槛，全站禁「正在生成 3D…」式文案）
- 截图介质盲区：动效单项改用录屏送审（本轮新增流程，评审看录屏 ≤3 分钟）
- 测量：录屏盲审 + reduced-motion 模拟截图

## 6. 交互（当前 7.5 → 目标 ≥8）

- 每个可点对象 hover/active/focus 三态齐备（键盘 focus-visible 可见）；触控目标 ≥44px
- 核心闭环（逛→看牌→看碑→投递）每步有独立视觉反馈；投递五重反馈结构**勿动**（R1–R8 全员认可），只可强化材质层
- 测量：三态截图组 + 键盘走查

## 7. 信息设计（当前 7.5 → 目标 ≥8.5，本项目的长板要拉开）

- 3D 编码必配图例（碑高=总包·灯条=五险·顶灯=下班 是标杆句式）；新增编码先入 `signature.md` 词典再实现
- 任何浮字禁穿透面板、禁视口裁切；A/B 对比页 B 标签裁字 = 待修事故
- 数据→空间映射**诚实**：山高严格线性、放大系数披露常驻、低薪不许虚高（低薪的山就是小——空场用道具群解决，不用改山）
- 测量：评委动线走查（第一屏→街区→单人→A/B→办公室，每屏一问「这是什么数据？」）

## 8. 氛围（当前 5.0 → 目标 ≥7.5）

- 每帧交付截图必须能回答「第一眼像不像有人花钱做的」——花钱感 = 克制 + 一致，不是堆料
- 昼基调「产业园区开放日」（明亮/规划感）、夜基调「霓虹夜市+测绘图纸」（禁赛博朋克模板）、单厂基调「测绘工作室」
- 禁止清单：蓝紫粉赛博 overload、无语义霓虹字牌、与词典无关的装饰物、通用城市模板件（喷泉/摩天轮式凑数地标）
- 测量：盲审「这帧像谁做的？像那个价位的产品吗？」

## 9. 工程红线（违反 = 事故，与视觉分无关也拦停）

- 街区 draw calls ≤200（现 678，街道纵深道具必须与合批同纸设计）；首屏 ≤5MB；目标 60fps（现越肩 13.5–14.5）
- Canvas 内禁裸 div / data-*（T13）；instanceColor 不开 vertexColors（T14 黑棚顶）；阴影面必挂贴图（白幕）
- 受限资产（*interiorgs*、*.ply）禁入 `web/public/`；运行时第三方 CDN 依赖一律自托管
- 相机机位变更必须对全建筑包围盒做相交验证（T9 全黑视角）
- 街区布局常量 `START_ALONG=14`、`SLOT_GAP=3.6` 勿动（T10 摊位吞没）

## 10. 奖项申报门槛（止盈条件）

- 全部单项盲审视觉 ≥8 且无未处理事故 → 按「功能/视觉修复版」部署双端 + `tools/accept-live.mjs` 线上验收
- 交付物：8 维度前后对照图 + 奖项申报建议（投哪个奖/类别/截图组合）——评审动线三件事自检：第一眼惊艳、5 分钟内到达签名时刻（钞票山/生长动画）、离场记得住「把画的饼，砌成真的山」
