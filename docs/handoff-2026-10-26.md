### 六、环境约束与纪律（违反会出事故/被拦）

- **相机初始位必须对场景所有建筑包围盒做相交验证**（T9 事故：初始机位落在 lot0 办公楼内=全黑视角）。现采用：初始高位鸟瞰 → 首次交互后越肩跟随 → 靠近摊位静止自动 3/4 特写（focus camera，见 RoamCamera.tsx）
- **街角体积**：新增/移动摊位前必须检查相邻街办公体块包围盒。当前 `START_ALONG=14`、`SLOT_GAP=3.6`；把起点改回 10 会让街角摊位被邻街办公楼吞掉（T10）
- **HR 真 GLB 近景已恢复**：动画必须用玩家 `avatar-idle.glb` 的 clip（HR 自带 clip 是 T-pose）；`NEAR=18`，占位仅远距/加载回退（见 T10 与 lessons 7.6）
- **InstancedMesh 矩阵必须写在 `useLayoutEffect`**，不能写 `useMemo`（ref 首渲染为空，矩阵永不生效；路灯曾全叠在原点）
- **任何共面装饰层**（窗/玻璃/LED/门）必须拉开 ≥0.02m 的 z 层级，否则远看是"涂鸦噪点"（T11）
- **InstancedMesh 山体布局数学陷阱**：`ceil(sqrt(N))²≥N` 恒成立——层数换算必须用固定层容量（现 3×3=9），否则金额差无法变成高度差
- **MSYS 路径转换**：Git Bash 会改写路径形态环境变量——构建配置一律用非路径令牌（VITE_BASE_TOKEN=ghpages/modelscope）
- **资产路径**：必须走 `engine/asset.ts` 的 assetUrl()（硬编码 /assets 会 404 挂整个应用）
- **安全纪律**：外联脚本必须 URL 白名单+私网拦截；key 只存 `.env`；生成物文件名避开 tokens.js 形状（某些安全扫描按文件名拦截）
- **Aholo API**：provider status=4 偶发→每步 3 次重试；真钞主题会被内容审核拦；批量脚本遵循 `tools/gen_v2_batch.py` 模式（mkdir 先行 / taskId 恢复 / 存档 docs/iterations/）
- **设计盲审**：只给截图不告知实现；≥7 分放行上线（8+ 为冲刺目标，当前 6.7/6.1）
- **单会话纪律**：同工作区禁止两个 Agent 并发（历史上冲突三次）
- egolite 是本机主力浏览器（所有 Agent 通用，`ego-browser` CLI 驱动）——运行规则与边界见 lessons.md 7.3 与上文第四节
